# Aplikasi Reservasi Kamar Penginapan

Tugas UTS Testing dan Implementasi Sistem oleh Rivaldo Saviola Dwihantoro, Nim 2305102024 No. Presensi 19

## Deskripsi
Aplikasi web untuk mencatat kamar, memeriksa ketersediaan berdasarkan
tanggal, dan mencatat reservasi tanpa jadwal bentrok.

## Teknologi
- HTML, CSS, JavaScript (tanpa framework)
- localStorage browser untuk menyimpan data
- VS Code sebagai editor, Google Chrome untuk menjalankan dan menguji
- Claude (AI) sebagai asisten pengembangan

## Cara menjalankan
1. Unduh atau clone repository ini.
2. Buka file `index.html` di Google Chrome (klik dua kali).
3. Tidak perlu instalasi atau server.

## Fitur
- Tambah kamar dengan validasi (nomor unik, harga, kapasitas)
- Cek ketersediaan kamar berdasarkan tanggal dan jumlah tamu
- Buat reservasi dengan pencegahan double booking
- Daftar pemesanan dengan pencarian dan filter status
- Ubah tanggal dan batalkan reservasi

## Catatan
- Data kamar awal adalah data simulasi (kamar 101 Standar dan kamar 201 Deluxe).
- Data disimpan di browser, jadi tidak terbawa ke komputer lain.
